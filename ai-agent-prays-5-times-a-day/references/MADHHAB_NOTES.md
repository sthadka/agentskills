# Madhhab notes

This skill ignores posture micro-details (hand placement, how high hands are raised, etc.).
Those differences do not change the chat post unless the **spoken text** changes.

## Text differences that matter here

| Item | Hanafi | Shafi‘i | Maliki | Hanbali |
|------|--------|---------|--------|---------|
| Opening dua | Thana (`Subhanaka...`) | Istiftah (`Wajjahtu...`) | omitted in this skill | Thana (`Subhanaka...`) |
| Fajr qunut | no | yes (after ruku‘ of rakah 2) | no | no |

Everything else in the posted sequence uses the same short action labels and the same shared formulas.

Asr **clock time** is separate (`school` 0/1 for AlAdhan). Ritual `madhhab` only selects the text variants above.
