# Feedback Template

Write session feedback to `{idea-name}/feedback.md`:

```markdown
# Feedback: {Idea Name}

## What Went Well
[Aspects of the session that were effective — specific, not generic praise]

## What Could Be Better

### Process
[Workflow improvements — phase transitions, annotation cycles, tool usage]

### Artifacts
[Document quality improvements — missing sections, unclear specs, plan gaps]

## User Effectiveness
[What the user did that made the session productive, and suggestions for
getting even more value from future sessions]

## Skill Improvements
[Concrete changes to SKILL.md, templates, or sculptor.py. Each item should
name the file, section, and describe the change — not just "improve the template."]

## Other Notes
[Ideas, patterns, or observations that don't fit above]
```

## Guidance

- Be specific. "The spec was good" is useless. "The spec's Data Model section had exact schemas which let the plan skip a discovery task" is useful.
- Skill improvements should name the file, section, and describe the change — not just "improve the template."
- Focus on what would make the NEXT session faster, not on what happened in this one.
